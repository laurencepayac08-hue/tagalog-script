Tagalog Script Playground

Write programs with Tagalog keywords and run them in your browser. Your code stays on your device.

Keywords

  

    
itakda
set a variable: itakda bilang = 1

    
sabihin
print a value

    
kung, kundi, tapos
if, else, and the end of a block

    
habang, tapos
repeat while a condition is true

    
gawin, ibalik
define a function and return a value

    
totoo, mali
true and false

    
at, o, hindi
and, or, not

    
#
a comment until the end of the line
